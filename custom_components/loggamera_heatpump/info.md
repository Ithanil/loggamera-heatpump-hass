# Loggamera Heat Pump

This custom integration fetches heat pump snapshots from the Loggamera API.

- Uses the Loggamera API [HeatPump endpoint](https://documenter.getpostman.com/view/6665372/S11HtyXG)
- Requires: Loggamera account, heat pump device, and API access
- Update interval: 15 minutes

Based on the original power meter integration by Svante Jacobsen:
https://github.com/svante-jacobsen/loggamera-home-assistant
